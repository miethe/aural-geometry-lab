# DR-13 — Multimodal Mathematical Visualization and Accessibility

**Current date:** 2026-08-14  
**Program:** Aural Geometry Lab

## Mission

Design an evidence-based multimodal representation system so AGL's mathematics remains understandable across visual, auditory, motor, and cognitive access needs without reducing the product to static text alternatives.

## Questions

1. Which visual encodings are most reliable for phase, rhythm, pitch, topology, recursion, graph traversal, and dynamical systems?
2. Which encodings become misleading when animated or mapped to sound?
3. How should selected, related, causal, and predicted states be represented redundantly beyond color?
4. What semantic model should accompany Canvas/WebGL/Metal visualizations for screen readers and keyboard users?
5. What sonification practices are useful for accessibility versus creative mapping, and how should those roles be distinguished?
6. How should reduced-motion mode preserve temporal mathematical information?
7. What are good interaction targets, keyboard-navigation structures, and focus models for rings, grids, lattices, trajectories, and tilings?
8. How can complex equations and live substitutions be presented accessibly?
9. How should AGL support users with color-vision differences, low vision, hearing loss, motor limitations, and cognitive-load sensitivities?
10. What automated and human accessibility tests are required?

## Required outputs

- visualization encoding grammar;
- semantic tree/list representation for each lab;
- accessibility contract for node graph and timeline;
- keyboard/focus navigation models;
- non-color token recommendations;
- reduced-motion behaviors per lab;
- screen-reader example announcements;
- user-test protocol;
- WCAG/platform-guidance mapping;
- changes to design spec/components;
- acceptance fixtures where machine-testable.

## Evidence requirements

Use primary accessibility standards, platform accessibility guidance, peer-reviewed visualization/HCI research, and primary sonification literature. Distinguish empirical evidence from design inference.
